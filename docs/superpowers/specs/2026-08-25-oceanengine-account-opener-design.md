# 巨量引擎账户页批量打开扩展：设计说明

## 目标

提供一个本地 Chrome 扩展，让使用者粘贴一批巨量引擎账户 ID，并为每个有效 ID 在新标签页中打开对应的事件管理页面：

`https://ad.oceanengine.com/oceanus/event_manager/own?aadvid={账户ID}`

## 范围

### 包含

- 工具栏弹窗中的账户 ID 多行输入框。
- 以换行、英文逗号或中文逗号分隔账户 ID。
- 去除首尾空白、自动去重，并只接受纯数字 ID。
- 为每个有效 ID 新建一个目标页面标签页。
- 显示有效账户数量与无效内容提示。
- 将最近一次输入仅保存在浏览器本机，供下次打开弹窗时恢复。
- 可通过 Chrome 的“加载已解压的扩展程序”直接安装。

### 不包含

- 自动登录、读取或导出 Cookie、Token、授权信息。
- 读取、写入或修改巨量引擎后台页面数据。
- 提交任何广告或账户设置变更。
- 从 Excel 或云端自动导入账户。

## 架构与组件

采用 Chrome Manifest V3。

- `manifest.json`：定义扩展名称、图标、弹窗、最小权限以及允许打开的巨量引擎页面范围。
- `popup.html`：输入区、操作按钮、结果状态和简短说明。
- `popup.js`：解析文本、校验并去重 ID、保存输入、请求后台打开标签页。
- `background.js`：接收已校验的账户 ID，为每项调用 Chrome 标签页 API，打开固定模板的目标地址。
- `styles.css`：弹窗的清晰、紧凑视觉样式。

## 数据流与交互

1. 使用者点击扩展工具栏图标。
2. 弹窗从本地扩展存储恢复最近一次输入。
3. 使用者粘贴或编辑账户 ID，支持换行、`,`、`，`。
4. 点击“批量打开”。
5. 弹窗解析输入，过滤非纯数字内容，按首次出现顺序去重。
6. 若不存在有效 ID，页面原地显示提示，不打开标签页。
7. 若存在有效 ID，弹窗将原始输入保存至本地，并把有效 ID 发送给后台脚本。
8. 后台脚本为每个 ID 新建一个标签页，URL 仅由固定路径和经过编码的 ID 构成。
9. 弹窗显示“已打开 N 个页面”；若发现无效项，同时提示其数量。

## 失败处理与安全边界

- 输入为空：提示需要至少一个账户 ID。
- 输入中夹杂非数字项：有效项仍可打开，并汇总无效项数量。
- Chrome 标签页 API 失败：在弹窗显示可理解的错误提示。
- 扩展仅请求打开目标站点所需权限和本地存储权限；不请求网页读取、账户数据读取或任何身份凭据权限。
- 扩展生成 URL，不检查、修改或保存巨量引擎页面中的内容。

## 验收与测试

- 给定单个 ID，生成且只打开一个精确目标 URL。
- 给定由三种分隔符混用的一批 ID，按去重后的有效 ID 数量打开对应标签页。
- 重复 ID 只打开一次。
- 空白、字母或混合字符不产生页面，并给出提示。
- 最近一次输入在重新打开弹窗时恢复。
- 使用静态检查与手工加载后的弹窗交互验证扩展包完整性。
