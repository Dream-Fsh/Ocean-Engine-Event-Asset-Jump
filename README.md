# 巨量账户页批量打开

这是一个本地 Chrome 扩展：粘贴一批巨量引擎账户 ID，即可在新标签页批量打开各自的事件管理页面。

## 在 Chrome 或 Microsoft Edge 安装

### Chrome

1. 在地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择本项目目录。

### Microsoft Edge

1. 在地址栏打开 `edge://extensions/`，或依次进入“扩展” → “管理扩展”。
2. 打开左下角的“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择本项目目录。

安装后，将“巨量账户页批量打开”固定到工具栏并点击使用。

## 使用

在输入框中粘贴账户 ID，支持每行一个、英文逗号或中文逗号分隔，例如：

```text
1860144197120064
1860144197120065，1860144197120066
```

点击“批量打开事件管理页”。每个有效账户 ID 会在新的后台标签页打开：

```text
https://ad.oceanengine.com/oceanus/event_manager/own?aadvid={账户ID}
```

扩展会自动忽略空白、重复和非纯数字内容；最近一次输入仅保存在当前浏览器的扩展本地存储中。

## 安全边界

扩展不会读取、保存、导出或上传 Cookie、Token、登录信息或巨量引擎页面数据，也不会修改后台中的任何内容。
